SAKSHI SHRIVAS PORTFOLIO — UPDATED VERSION

RUN LOCALLY
1. Extract this ZIP file.
2. Open the Portfolio folder.
3. Double-click index.html. For the GitHub repository section and Google/Font Awesome assets, keep internet access enabled.

FEATURES
- Dark/light theme toggle (preference is saved in the browser).
- Responsive mobile navigation and back-to-top button.
- Animated role headline and reveal effects.
- Project search, category filters, and details popups.
- Certificate search/filter and a PDF preview/download for the Python certificate file included in the original ZIP.
- Resume preview and download.
- GitHub public repository cards fetched from the GitHub API, with a profile fallback.
- SEO descriptions, Open Graph metadata, theme color, favicon, and social preview graphic.
- Contact form opens a prefilled email draft in the visitor's default email application.

IMPORTANT
- The original ZIP included only the Python certificate PDF. Other certificate cards are clearly marked as unavailable until you add their actual PDF/image files. To activate a card, place its file in this folder and wire that card to the correct filename.
- The original ZIP did not include a personal photo, so the hero uses a stylized SS initials illustration. Replace it with your photo only if desired.
- Because this is a static HTML website, the contact form does not store/send messages on its own. It opens the visitor's email app. For direct delivery without an email app, deploy a backend or connect a form service.
- A LinkedIn profile URL was not supplied, so the LinkedIn icon links to LinkedIn's homepage rather than inventing a personal URL. Update it when you have your profile URL.
- Some original project GitHub buttons point to the profile because exact repository URLs were not provided.
